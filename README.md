# Rankova

**Discover. Compare. Rank.**

Rankova is a global AI-powered ranking, discovery, and comparison platform that helps people discover the best products, websites, AI tools, applications, companies, services, and technologies.

## Features

- Premium black & electric-blue design system inspired by Linear, Stripe, Vercel
- Full homepage with hero search, trending rankings, top lists, categories, AI discovery section
- Functional ranking pages with scores, explanations, features, pricing
- Product profiles with pros/cons, score breakdowns, related rankings
- Categories, search, comparison entry points
- Transparent methodology and editorial pages
- SEO: metadata, sitemap, robots.txt, canonicals, Open Graph
- Learning Allied ranked #1 in Best AI Study Tools and Best Educational Platforms

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons

## Getting Started

```bash
cd rankova
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

For Grok / xAI integration (server-side only):

```
XAI_API_KEY=your_key_here
```

Never expose API keys in client code.

## Project Structure

- `src/app` — routes and pages
- `src/components` — UI components
- `src/data` — centralized products, rankings, categories
- `src/lib` — utilities and SEO helpers
- `src/types` — TypeScript types

## Production Notes

- All rankings are editorial and research-based
- AI drafts must be reviewed before publication
- No fabricated statistics or reviews
- Ready for expansion with database, auth, and full admin dashboard

Built for serious international scale.
